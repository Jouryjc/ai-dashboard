# 准确性、体验性与安全性

## 准确性

- 将用户业务目标分解为可追溯 capability、acceptance criterion 和 scenario。
- 每个必需需求必须映射到模块/视图和至少一个可执行场景。
- 场景断言真实状态变化：创建后出现记录、编辑后字段变化、删除后记录消失、详情真实导航、状态流转需确认并产生结果。
- 参考图文字识别不可靠时记录 unknown，不猜测关键业务字段。
- 模型输出只能作为候选，必须通过 Schema、跨引用、变更范围和运行时门禁。
- 所有 Revision 携带 Manifest 与 ValidationReport；发布前再次校验。

## 体验性

- dashboard 优化“一屏看全”；business-app 优化“任务完成”，不要混用评价标准。
- business-app 固定验收 `1920×1080` 与 `1366×768`，每个场景在独立页面执行，避免状态污染。
- 页面必须有明确应用壳、模块导航、当前视图、主操作、结果反馈、加载/空/异常或数据模式说明。
- 创建、编辑、详情等使用独立业务视图或清晰步骤，不用左下角提示代替功能。
- 高风险操作必须在上下文中解释影响并二次确认。
- 澄清只问真正阻塞生成的问题，每轮一个；选项说明后果、推荐原因和风险，并允许自定义回答。
- 进度必须反映真实节点，失败或看门狗接管时关闭遗留 active step，禁止界面永久转圈。
- 文案使用简体中文大白话；技术细节放进“详情”或日志，不直接压给业务用户。

## 安全性

### 输入与模型边界

- 在需求契约前脱敏 API Key、Bearer Token、密码、私网地址和其他凭据。
- 不把凭据写入 Prompt、蓝图、源码、日志、版本证据或测试快照。
- 本地模型配置只写入被忽略的本地环境或设置文件；提交前检查 `.env*` 与暂存区，不因用户曾在对话中提供密钥就把它复制进文档或示例。
- connected 模式必须确认接入边界并绑定已授权 connector id；凭据仍由安全配置管理。
- 限制图片格式、大小、裁剪区域和模型返回字段长度。
- 规范化模型 JSON；拒绝脚本、URL、私密数据、越界 ID 和未授权组件。

### 构建与预览边界

- 文件路径必须相对、规范化并匹配白名单，拒绝 `../` 和绝对路径。
- 限制文件数、源码体积、构建日志和执行时间。
- 只允许精确版本依赖和受控 import；禁止任意 npm 包。
- 禁止 `eval`、`Function`、fetch、WebSocket、XHR、Worker、外部导航和远程脚本/样式。
- 构建子进程只继承必要系统变量，不继承模型密钥。
- 预览不得访问外部 origin；浏览器验收必须监听 console、pageerror 和 request。
- 证据文件只记录来源、版本、提交和哈希，不保存图片本体或密钥。

### 状态与恢复边界

- GraphCheckpoint 与可信 FlowDefinition 分离；验证 flow id/version、拓扑和字段类型。
- 用户新需求重置本轮 scoped decisions，续跑才复用候选和检查点。
- 未通过门禁的候选不得晋升为 current revision。
- 历史回退不可变，发布动作必须指向明确且已验证的版本。

## 修复闭环

每条失败 gate 都形成：

```text
期望行为 + 实际证据 + 可重复步骤 + 修复范围 + 通过条件
```

修复策略必须有界、可审计、可复检：

1. 恢复可信样式/配置等确定性修复。
2. 只允许模型修改批准的展示源码文件。
3. 根据失败场景定向重新规划目标模块。
4. 扩展相关 IDux 证据后重新规划。
5. 策略耗尽或缺少授权时，才请求用户调整需求或人工协助。

不要吞掉异常后返回成功，不要反复执行同一策略，不要在复检前标记 Issue fixed。

## 中文注释规范

- 新文件使用文件头说明职责、上下游和关键边界。
- 公共接口、领域类型、导出方法和复杂私有方法使用 `/** ... */`。
- 注释解释“为什么、约束、输入输出和失败语义”，不翻译语法或复述变量名。
- 安全正则、状态恢复、增量合并和非直观回退必须写就近注释。
- Prompt 内说明与代码注释分开；生成文件可标注来源和禁止绕过的契约。
- 修改逻辑时同步更新过期注释；禁止中英文混杂的模板式占位注释。
