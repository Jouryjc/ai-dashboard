Review whether the selected page pattern matches the actual task and data, not whether the screen resembles AWS. Verify application/module/view hierarchy, action scope, collection completeness, detail structure, form recovery, destructive-action friction, state coverage, IDux identity, task density, and scroll ownership at 1920×1080, 1366×768, and the embedded workbench. Treat universal KPI-card-plus-table composition, decorative empty space, hidden primary tasks, clipped content, fake actions, and inline destructive confirmation as major failures.
