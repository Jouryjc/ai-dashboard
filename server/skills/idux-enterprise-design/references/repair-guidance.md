# Runtime repair guidance

Repair the layer that owns the failed contract. Restore trusted theme or shell assets deterministically; repair generated view code only for localized rendering defects; replan the target module when the page pattern, action model, state coverage, or information architecture is wrong; expand IDux and enterprise-pattern evidence when the plan lacks a supported component composition. Preserve unrelated modules and repeat static, build, runtime, scenario, network, responsive, and visual checks after each attempt.
