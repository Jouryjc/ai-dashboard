# 大屏设计语言(无参考图创作规范)

从已验证大屏蒸馏的设计系统。**无参考图时,本文件是审美依据**;有参考图时,参考图优先,本文件只补缺口。组件级 CSS 片段见 [big-screen-patterns.md](big-screen-patterns.md),本文件管"怎么选、怎么排、怎么配"。

## 画布与骨架

- 设计稿固定 16:9,宽 1749-1920px,`transform: scale()` 等比适配,不做流式重排。
- 按主题选骨架,不要发明第四种:

**骨架 A · 指挥中心型**(适合:运行监控、应急指挥、运维总览)
```
┌──────────── 大标题(居中发光)+ logo + 时钟 ───────────┐
├──────────── 顶部指标条(5-7 张统计卡)──────────────┤
│ 左栏(2 面板)  │   中央地图 + 底部宽表   │ 右栏(3-4 面板)│
└──────────────────────────────────────────────┘
```
左栏=资源/状态,右栏=告警/安全/排名,中央=地图+明细表。栏宽比 ≈ 25% / 50% / 25%。

**骨架 B · 平台运营型**(适合:云平台、销售运营、多分区管理)
```
┌─ 标题板 + 页签统计 + 右侧指标组 ─┬─ 右列标题 ─┐
│ 浮动资源卡行(3-4 张,带页签飘带) │ 面板 1    │
│ 中央大地图(数据中心/链路)      │ 面板 2    │
│ 底部横条(评分 + 告警,2 面板)   │ 面板 3-4  │
└─────────────────────────┴────────┘
```
卡片浮在地图上方(z 分层),右列纵向堆叠 3-4 个面板贯通到底。

**骨架 C · 纯面板网格**(适合:无地理信息的业务分析)
```
标题 + 指标条;下方 2-3 列 × 2-3 行等宽面板网格,面板类型错开(图/表/排名/仪表)。
```

## 色彩系统

| 角色 | 值 | 用途规则 |
|---|---|---|
| 深底 | `#04102e → #02071a` 纵向渐变 + 2 处径向辉光 | 全屏铺底,不用纯黑 |
| 主青 | `#37e0ff` | 大数字、进度填充、高亮描边,带同色 `text-shadow` 辉光 |
| 主蓝 | `#2b8bff / #1d6cff` | 面板边框、渐变填充、排名徽章 |
| 正文 | `#cfe3ff` / 次级 `#8fb4e4` / 弱 `#7ea6d8` | 三级文字灰度,不用纯白铺大面积 |
| 语义色 | 好 `#2ee6a8`,警 `#ffb84d / #ff9d5c`,危 `#ff4d5e` | 只标状态,不做装饰 |
| 无数据 | `#5b6b85` | 禁用/空态 |

纪律:语义色家族 ≤ 4 个;每张图 1 个主色 + 中性底;警示色只出现在真正的警示数据上。浅色主题另起令牌(本文件以深色为默认,深色是数据大屏品类惯例)。

## 字体与数字

- 字体栈:`"PingFang SC","Microsoft YaHei",sans-serif`;数字专用 `"Bahnschrift","DIN Alternate",sans-serif`(tabular,不加字距)。
- 字号阶梯:大屏主标题 30-40px/800 → 面板标题 16px/700 → 大数字 22-32px → 正文 13px → 辅助 11-12px。不连续缩字号,按阶梯取。
- 大标题:渐变字(`#eaf6ff → #7fc4ff`,`background-clip:text`)+ 辉光 + 字距 4-6px;可加翼线和下划光带。
- 单位跟数字走但降两级(`<small>` 12-13px、浅色)。

## 面板与镀铬

- 面板三件套:半透明深蓝渐变底 + 1px 蓝边 + 四角直角括号(2px `#3fb4ff`)。不要圆角卡片堆卡片。
- 面板标题:16px,左侧 4px 发光竖条,底衬斜切渐变条(`clip-path` 右切角)。
- 重要浮卡(骨架 B 资源卡)可用 8px 圆角 + 内高光 + 页签飘带。
- 分隔用 1px 半透明线或虚线,不用粗边框。

## 组件选型

| 数据形态 | 组件 | 备注 |
|---|---|---|
| 单个大数字 | 统计卡(图标+发光数字+标签) | 顶部条 5-7 张,卡内数字 ≤ 12 字符 |
| 利用率/占比 | 环形仪表(62px,6px 描边) | ≥80% 换警示黄;一排 3-4 个 |
| 分类构成 | 四色堆叠条 / 环形图 | 环形图 ≤ 6 段,中心放总数 |
| 排名 | 徽章+段式虚线条 | TOP3 实心徽章,4-5 半透明 |
| 分级计数 | 三色横条(紧急/中等/轻微) | 宽度按最大值归一 |
| 明细流水 | 表格 | 斑马纹 `rgba(30,70,160,.12)`,行高 28-32px |
| 趋势 | 折线/面积图 | 单系列主青,参考线虚线 |

## 地图

- 一律用真实 GeoJSON(脚本转换内联),不手画轮廓。
- 平面地图:深色填充 + 亮描边 + 渐变高光区 + 节点脉冲 + 虚线飞线(stroke-dashoffset 流动)。
- 3D 俯视:用"压扁法"(形体组 `scale(sx>sy)`,标签组外换算),挤出层 `rgba(8,20,52,.9)` 下移 14×SY。
- 地图上图层从下到上:挤出层 → 行政路径 → 链路 → 光柱/光点 → 文字。

## 密度与节奏

- 一屏 6-9 个面板;每个面板只讲 1 件事(1 个主数字或 1 张图),其余是支撑。
- 视觉重心唯一:地图或最大的图 = 重心,其余面板降亮度降饱和度。
- 数字大、标签小、单位更小的三级对比是"大屏感"的核心来源。
- 留白集中在面板之间(12-22px gutter),面板内部紧凑。

## 动效

只用三类:数字时钟(1s)、节点呼吸(opacity 2.4s)、飞线流动(dashoffset 1.6s)。不加入场动画、不加悬浮缩放。全部包 `@media (prefers-reduced-motion: reduce)` 静态降级。

## 创作流程(无图模式)

1. 确认主题与数据:用户没给数据就用示例数据,并在面板/描述里标注"示例数据";不编造看似真实的业务指标名。
2. 按主题选骨架(A/B/C),列出面板清单(每面板:标题、组件、数据形态)。
3. **先算高度预算**:header + 指标条 + 主区 ≤ 设计高;每栏面板高 + 间距 ≤ 栏高。算完再写码。
4. 按 big-screen-patterns.md 的片段组装,配色只取本文件令牌。
5. 截图校验闭环(≥2 轮),检查表同复刻模式。
6. 上架流程同复刻模式。
